# Quack
Платформа, яка поєднує електронний щоденник з персональними профілями та внутрішню комунікацію між студентами і викладачами.

## Scope
| Частина системи | Технології |
|-----------------|------------|
| Design          | Figma |
| Frontend        | React + TypeScript (Vite) |
| Backend         | Django + DRF |
| Authentication  | JWT |
| Database        | PostgreSQL |
